✅ Sudah pernah install aplikasinya?

Sebagian HP memblokir website membuka aplikasi lain secara otomatis demi keamanan. Kalau aplikasi IKT Online / SAT OPR Mobile sudah ada di HP-mu, cukup buka manual:

  1. Tekan tombol Home di HP
  2. Cari ikon aplikasinya di layar utama / laci aplikasi
  3. Tap untuk membuka seperti biasa
